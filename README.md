# pair-wise-yf-52 戏剧排练台词版本与舞台提示管控

## 源提示词摘要
导演、编剧、舞台监督和演员共同维护不同版本的剧本、角色台词、上下场提示、道具与灯光音效提示。编剧提交后需逐条合并，演员可查看最新版并标记疑问；支持版本对比、单条采纳、批注、冲突处理、排练模式、大字号提词和断网缓存。

## 技术栈
Angular + TypeScript + Angular Material + NgRx + Angular Router + RxJS + Angular CDK + Transloco。

## 排练窗口与待同步队列
- 窗口里可同时编辑**角色台词**（舞台监督采纳/退回、拖拽排序）和**舞台提示**（采纳/退回、导演改计时）。
- 所有改动先进入**待同步操作队列**（标注来源：舞台监督/导演，并锚定版本与来源 revision），窗口显示「记住的改动版本」，正式快照不动。
- **整批写出**：全部 queued 操作一次性落盘，成功后才替换正式快照；失败（含离线、可注入的 503）时队列原样保留，可整批重试。
- **冲突不静默覆盖**：排队期间来源侧改了文本/计时、删了条目或调整顺序，操作按来源列出（对方来源、基线 revision、对方内容、冲突类型），由人选择「保留我的 / 采用来源 / 丢弃」。
- **来源或版本一变即失效**：切版本会让锚定旧版本的操作失效退回；来源条目缺失会显示「缺号」占位行，不能被静默补回。
- **旧数据迁移**：缺条目编号（含空串 id）时按「角色+文本」/「场景+文本+计时」文本指纹补号（`mig-<指纹>`）并标记「迁移补号」；旧存档缺 revision/timing 字段也会补齐。
- **排练提词模式只读**：直接读取已确认快照，仅展示 `accepted` 条目，大字号提词，队列/冲突/联调面板隐藏，任何待同步内容都不会混入。
- localStorage 持久化：版本、队列（含冲突与失效项）、写出错误状态都会缓存，刷新后仍可重试。
- 右栏「同步与来源联调」可模拟断网、制造写出失败，以及来源端改写台词、改提示计时、删除条目（缺号）、重排顺序。

## 验证
纯状态逻辑经 40 项断言验证：队列生成与窗口投影、整批成功/失败/重试、文本与计时冲突、缺号占位、版本切换失效退回、旧数据指纹迁移、同值操作自动撤队等。
